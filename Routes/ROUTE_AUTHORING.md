# Как вести маршрут APR вместе с игроком

Игрок на русском клиенте retail, в Хроми, в скобке нужного дополнения. Он стоит в мире и сам дописывает шаги. Агент планирует порядок и не записывает то, что можно снять только в клиенте.

Эталон прохода: `Routes/TheBurningCrusade/working_Nagrand_Horde.lua` и готовый `TheBurningCrusade_Nagrand_Horde.lua`.

## Кто что пишет

Игрок дописывает хвост рабочего файла. Только из его записи берутся:

- `Coord` — мировые ярды, не карта 0–100 и не 0–1
- `Button`, `SpellButton`, `LootItems.itemID`
- `GossipOptionIDs`, `NpcDismount`, `DroppableQuest.MobId`
- `Range`, если он его уже поставил

Агент не конвертирует проценты карты в ярды и не «уточняет» записанные числа. Карта 0–100 в ответе игроку — только ориентир, куда идти.

Агент называет квест, NPC, цель, развилку и следующий пункт. После «посмотри», «обновил», «сверимся» сначала читает хвост рабочего файла и говорит только то, чего в нём ещё нет.

Чужие записанные шаги не переписывать. Единственная правка по своей инициативе: стрелка увела сдавать квест раньше, чем закрыты цели. Тогда вставить `Qpart` на каждую ещё открытую цель и перенумеровать `_index` до конца.

## Как отвечать

Язык игрока — русский. Имена квестов и NPC — строка из клиента, не перевод с английского. Сверять по ru.wowhead. Пунктуация тоже из клиента: «Он будет странствовать по земле...», «РАЗЫСКИВАЕТСЯ: Дарн Ненасытный».

Список — нумерованный. Один пункт = одно действие. В каждом пункте название квеста в кавычках. Если у трёх ступеней одно имя, рядом писать цель: «Охота на копытней», копыто Бантара.

«Нет квеста» — назвать точное имя в журнале и кто его даёт. Не отправлять убивать цель без этого квеста: добыча не засчитается.

«Не дали следующий» — его выдаёт один конкретный NPC, вторым разговором, после того как предыдущий уже закрыт. Соседние NPC на той же точке его не дают. Нет жёлтого знака — не держать остальной круг.

«Почему не брать» — блокирует ли это остальные квесты и нужно ли оно достижению зоны. Не блокирует — вынести за соло-круг и сказать, когда вернуться.

## Порядок круга

Один географический круг, не хаб за хабом. Повторный заход к NPC только если сдача открывает квест, который делается по дороге к следующей сдаче. Эту причину писать явно.

Перед кругом выяснить, кто вообще заговорит: репутация, предварительный квест, предмет в сумке. Одноимённые зоны разных дополнений не смешивать. `mapID` — retail uiMapID, не старый zone id. Награнд TBC — 107, не Дренор. Шаг может лежать в соседней зоне: маршрут `mapID = 107`, а сдача `Zone = 108`.

Группа, PvP, подземелье и призыв элиты не входят в соло-круг. Квест в другую зону взять и оставить в журнале, из зоны не уводить.

Предмет будущего квеста не собирать, пока квест не взят: он начинает падать только после взятия. Репутационный квест пропадает на пороге фракции. Для Консорциума «Украсть у вора» и «Кость на вес золота» есть только на Равнодушии.

Текст квеста важнее ближайшего знакомого лагеря. Костры, ящики, знамёна и «грязь» стоят там, где сказано в задании, а не у NPC, которого уже видели. Финал цепочки с тем же названием открывается только после сдачи предыдущей ступени, и имя зверя в журнале может быть другим.

Жёлтый «?» над мобом — сдача. Серебряный «?» — баг, ждать респауна. Если квест требует подчинить, не вешать доты и оглушения.

## Файл

Пока идут в мире: `Routes/<дополнение>/working_<зона>_<фракция>.lua`.

Готовый маршрут — отдельный файл, ключ как у соседних зон этого дополнения. Для TBC Орда это `APR.RouteQuestStepList["<mapID>-BC-<n>-Horde"]`, заголовок как у `TheBurningCrusade_Hellfire_Peninsula_Horde.lua`: `expansion = APR.EXPANSIONS.TheBurningCrusade`, `category = APR.CATEGORIES.Leveling`, `conditions = { Faction = "Horde", Level = ... }`, `nextRoute` на следующую зону. Подключить одной строкой в `Routes/RouteList_Standard.xml`. Рабочий файл в список не добавлять.

`_index` сквозной, без дыр. Вставил шаг — перенумеровать хвост. Не коммитить, пока игрок не попросил. В коммит только файл маршрута.

## Поля шага

```lua
{
    Qpart = { [9889] = { 2 } },
    Fillers = { [9863] = { 1 } },
    Coord = { x = 6003.3, y = -3265 },
    Range = 5,
    Button = { ["9927-1"] = 25552 },
    Zone = 107,
    _index = 5,
},
```

- `PickUp` — квест ещё не в журнале. Шаг сам проходит, когда квест взят или уже сдан.
- `Done` — стрелка на сдачу сразу. Шаг сам не проходит, пока квест не сдан. Поставленный раньше закрытия целей, он ведёт игрока сдавать слишком рано. Перед ним нужен `Qpart` на каждую ещё открытую цель.
- `Qpart` — шаг проходит, когда перечисленные цели выполнены или весь квест сдан. Цели, которых нет в списке, шаг не держат. Индекс цели — порядок в журнале, с 1. Запись игрока важнее догадки.
- `Fillers` — другие цели на этом же месте. Видны игроку, шаг не держат.
- `DropQuest` — квест начинается с предмета. Шаг проходит, когда квест уже в журнале или сдан. Рядом `DroppableQuest = { MobId = ..., Qid = ..., Text = "..." }`. `MobId` только из записи.
- `Waypoint` — точка пути. Квест не закрывает. Число — id квеста, ради которого идут.
- `Button` — `["questID-objective"] = itemID`. `itemID` только из клиента.
- `LootItems` — считает предмет в сумке: `{ itemID, quantity, questID }`. `itemID` не выдумывать.
- `Range` в этом проходе: 5 — одна цель или объект, 15 — короткое сопровождение, 30 — лагерь. Уже записанный `Range` не менять.
- `Not = { IsQuestReadyForTurnIn = id }` — шаг сопровождения жив, пока квест не готов к сдаче. Готовность: квест взят и выполнен, либо уже сдан.
- `IsQuestOnQuest` — шаг только пока этот квест в журнале.
- `NpcDismount` — слезть перед NPC, который поднимает в полёт.
- `GossipOptionIDs` — только из записи диалога.
- `ExtraLineText` и `Note` — ключ локализации, например `PATROLS_AROUND_AREA`. Русскую фразу туда не писать. Нет ключа — поле не добавлять.
- `Zone` шага — uiMap, где стоит игрок. Может отличаться от `mapID` маршрута.
